# Seshat — aplicación web

Parte web del curso (Next.js + React). No se arranca desde aquí: usa
`../start.sh`, que levanta el motor de progreso y esta app juntos.

El contenido del curso vive en `data/` (validado en cada build), el motor de
ejercicios en `components/`, y la lógica compartida (corrección tolerante,
TTS, repaso espaciado, logros) en `lib/`.
